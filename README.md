# temp-controlled-fan

## Overview
This circuit uses the LM393 comparator to compare the voltage from an NTC thermister temperature sensor with a user-defined threshold. When the temperature measured by the NTC thermister exceeds the set threshold, a signal is sent to the NMOSFET, activating it, which in turn turns on an LED to indicate that the DC motor is running.
